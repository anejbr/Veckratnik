# Večkratnik

Spletna aplikacija z matematičnimi kvizi za osnovnošolce.

- **Backend:** FastAPI (Python)
- **Frontend:** React + TypeScript + Vite, Tailwind CSS, shadcn/ui
- **Baza:** PostgreSQL
- Vse teče v Docker containerjih, zaženemo z `docker compose`.

## Zagon

```bash
cp .env.example .env
docker compose up --build
```
